Built on v0.15.62 Alpha Monster Tracking. Includes all earlier updates.

INSTALL: Replace index.html and styles.css in your GitHub repository root.
Do not delete your assets, saved game data, or content folders.

NEW
- A Maze Streak counter appears immediately beneath Revealed Tiles in the regular Explore map header.
- Each completed and rerolled maze increases your streak by 1.
- Unfinished Mythic Temples / Alpha dens still block completion, so the counter only advances when the maze truly clears.
- The counter resets to 0 when you end an expedition or faint in battle.
- Like the existing active maze, the run streak does not persist across page refreshes.
- Mythic Temple chance and its independent clear counter are unchanged.
- Halloween maze escapes are not counted.

Tested via Node syntax check and isolated progression/reset tests.
