PRISMWILD LIVE CONTENT PUBLISHING • v0.15.41
============================================

WHAT LIVE CONTENT DOES
Prismwild now separates GAME BUILDS from CONTENT UPDATES.

A full game build is needed for code/system/UI changes.
A Live Content push is enough for Admin-authored content that the current build already knows how to use.

LIVE CONTENT INCLUDES
- Published custom Monsters
- Their uploaded Base / Prismatic / Egg art
- Published custom Attacks
- ALL Sprite Workshop replacements automatically
  • item icons
  • shop icons
  • Halloween/event icons
  • field-find art
  • facility art
  • Silverwind poses
- ALL current Silvy Dialogue
- ALL current Landing Page News and Announcements
- ALL current Trial definitions
- Trial Captain and Badge artwork

NOT PUBLISHED
- Player saves / collections / currency / inventory
- Account names or account roles
- Admin unlock state
- Event Tester force-active/inactive overrides
- Expedition Tester fast-forward state
- Other local testing state

FIRST DEPLOYMENT OF v0.15.29
1. Replace the files in your local GitHub Desktop prismwild-test folder with the contents of this v0.15.29 build.
2. Make sure content/prismwild-content.js exists.
3. In GitHub Desktop, Commit to main, then Push origin.
4. Refresh the public Prismwild site.

FUTURE CONTENT UPDATES • NO NEW BUILD NEEDED
1. Open your local/admin Prismwild copy.
2. Make your content changes in Admin.
3. For a custom Monster, check its Published box when it is ready.
4. For a custom Attack, check its Published box when it is ready.
5. Sprite Workshop, Silvy Dialogue, Landing Page, and Trial changes need no extra Published checkbox. Their current saved versions are included automatically.
6. Click Export Live Package.
7. Your browser downloads prismwild-live-content.zip.
8. Extract that ZIP directly into the ROOT of your local GitHub repository and allow matching paths to merge/overwrite.
9. The ZIP updates content/prismwild-content.js and assets/live/... together.
10. Open GitHub Desktop.
11. Commit the changed files with a short message such as "Update Halloween icons" or "Add NewMonsterName".
12. Click Push origin, then refresh the public site. Existing player saves remain separate from the shared content update.

DRAFT SAFETY
- New custom Monsters default to Draft.
- New custom Attacks default to Draft.
- Draft Monsters and Attacks are not included in Live Content.
- Export Live Content refuses to publish a Monster if its custom Signature Attack is still Draft.
- Sprite/Dialogue/News/Trial editors currently publish their SAVED state as a whole, so use your local Admin copy as the workshop and export only when those edits are ready.

BACKUPS
- Export Admin Data = full local workshop backup.
- Export Live Package = public publishing package ZIP.
- Keep occasional Admin Data backups somewhere safe. Live Content should not be your only backup.

STATIC-HOSTING NOTE
The public site cannot safely write directly to GitHub. Do not put a GitHub password or token inside Prismwild.
Publishing remains:
  Export Live Package -> extract ZIP into repo root -> Commit -> Push origin

LIVE CONTENT DIAGNOSTICS
Admin shows the currently loaded Live Content revision plus counts for Monsters, Attacks, Sprite overrides, Silvy lines, News, Announcements, and Trials. If a public update seems missing, compare that revision after refreshing the live site.


v0.15.30: Event Calendar prize configurations are part of the Live Content layer (schema v8). Event availability overrides, simulated Calendar Test Day values, Memory cooldown resets, and other tester controls remain local-only and are not published.


v0.15.31: Winter Gift Calendar is capped at 25 days. Imported or previously saved Winter calendar entries beyond Day 25 are pruned during normalization.


v0.15.32: Winter Event monster hooks are registry-driven. Published custom species using Winter Event Shop Egg automatically appear in the Snowflake Shop; Winter Mystery Egg species automatically enter the Mystery Egg pool; seasonal Crossbreeds can be assigned to Winter or Halloween through Monster Workshop and publish through Live Content.


v0.15.38: Trial Captain personality fields (Normal/Hard intro, victory, defeat, lore, philosophy) are part of the Trial definition and publish through Live Content. Trial Captain art continues to publish with Trial assets.


v0.15.40: The packaged Live Content includes the current Nature and Magma Trials, their Captain art/dialogue/lore, Aeralith, Cirrulong, and Flamecoil. The Haunted Maze continues to derive tagged event encounters dynamically.


v0.15.41: Published image assets moved out of prismwild-content.js into assets/live/... files. Export Live Package now produces a ZIP containing both the lightweight content JS and all published image files. This avoids GitHub's 100 MB single-file limit while preserving portable Admin Data backups.
